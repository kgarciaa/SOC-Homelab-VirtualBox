This project uses multiple virtual machines within VirtualBox to simulate a Security Operations Center (SOC) environment focused on security monitoring, log analysis, and SIEM operations. The virtual machines used in this project include Ubuntu, Windows Server 2022, Kali Linux, Metasploitable, and pfSense, with Splunk Enterprise serving as the centralized SIEM platform for log collection, monitoring, and analysis.

In addition to defensive monitoring, the project incorporates offensive security and red team concepts by using Kali Linux to perform reconnaissance, service enumeration, authentication testing, and other simulated attack activities against systems within the lab. Activities generated by the attacker machine are analyzed through logs collected in Splunk, allowing for the investigation and detection of simulated attacks from a blue team perspective.

Future testing will include password attack simulations, denial-of-service testing, and other controlled security assessments performed within the isolated lab environment. The objective of these exercises is to observe how different attack techniques appear in system and security logs, develop detection strategies, and improve incident investigation and response capabilities using Splunk.
